3เกณฑ์ออกแบบที่จะใช้ใน Phase 3

  • วิธีออกแบบ: LRFD ตาม AISC 360-16 (วสท. ยอมรับ) · combos 1.4D · 1.2D+1.6L+0.5Lr · 1.2D+1.6Lr+0.5L · 1.2D+1.0W+0.5L · 0.9D+1.0W · ตรวจ serviceability ที่ค่าใช้งาน
  • วัสดุ: หน้าตัดรีดร้อน SS400 (Fy 245) · girder ทางเลือก SM520 (Fy 355) · แป/girt C เย็น TIS 1228 SSC400 ชุบสังกะสี · tie rod SR24 · สลักโครงหลัก F10T / A325 · secondary 8.8 · anchor SS400
  • Live load: พื้นยิม/mezz/front L2 5.0 kPa · บันได 5.0 kPa · ราว 0.75 kN/m แนวนอนที่ +1.1 · หลังคา 0.30 kPa (กฎกระทรวง) + จุด 1.0 kN ที่แป
  • Dead load เพิ่ม: slab composite 120 มม. 2.6 kPa · finish/ฝ้า/งานระบบ 1.0 kPa · หลังคา sheet+ฉนวน 0.15 kPa · ท่อแอร์แขวน 0.25 kPa (โซนท่อ)
  • ลม มยผ. 1311-50: สงขลา กลุ่ม 4A V50 = 25 m/s, TF = 1.2, Iw = 1.0 (ต้องเปิดตาราง ภาคผนวก ก ยืนยันอีกครั้งตอนคำนวณ) · วิธีอย่างง่าย อาคารสูง ≤ 23 ม.
  • Deflection: คาน/mezz L/360 (LL) · L/240 (รวม) · แป L/180 · drift เสาโซนปีน H/200 (เข้มกว่า H/150 เพราะผนังปีน)
  • Vibration: พื้น bouldering + mezz ตรวจตาม AISC Design Guide 11 (rhythmic + walking), เป้า fn ≥ 9 Hz สำหรับพื้นออกกำลังกาย
